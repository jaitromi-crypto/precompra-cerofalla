# Cero Falla · Revisión Precompra

Aplicación web/PWA para realizar inspecciones de precompra automotriz desde celular o tablet.

## Incluye
- Checklist por áreas
- Estado por ítem: Bueno / Observación / Deficiente / N/A
- Observaciones por ítem
- Fotografías de respaldo
- Historial local en el dispositivo
- Resumen de hallazgos
- Preparación de respaldo para Google Drive
- Instalación como PWA

## Publicación con GitHub Pages
1. Sube todos los archivos de este paquete a la raíz del repositorio.
2. En GitHub entra a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige **main** y la carpeta **/(root)**.
5. Guarda.

GitHub mostrará la URL pública cuando termine el despliegue.
